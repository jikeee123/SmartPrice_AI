# 内网访问

双击项目根目录的 `run_lan.bat` 启动。服务监听所有网卡的 TCP 8502 端口，本机原来的 8501 服务可以继续使用。

当前发布地址：http://172.18.102.89:8502

其他人的电脑或手机接入同一内网后，在浏览器中打开该地址即可使用平台。预测、定价、AI助手等交互均由本机服务处理；保存的审批和运行记录共用本机数据库。

主机需要保持开机、联网且不休眠。网络变化后 IP 可能改变，可运行 `ipconfig` 查看 WLAN 的 IPv4 地址，替换网址中的 IP。需要长期固定地址时，请让网络管理员分配固定 IP 或 DHCP 地址保留。

重新启动：关闭旧的内网服务后双击 `run_lan.bat`。手动启动的窗口中按 Ctrl+C 可停止服务。

如其他设备打不开，先确认它们能访问该内网主机；部分访客 Wi-Fi 或校园网络会隔离设备，需要网络管理员允许设备互访和 TCP 8502。Windows 防火墙启用时，也需允许该端口的内网入站访问。

当前平台没有登录和角色权限，能访问此网址的人可以操作并保存记录。请仅向可信内网成员分享。
