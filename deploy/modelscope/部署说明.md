# SmartPrice AI 免费托管包

此包用于魔搭创空间的Streamlit类型，不需要自购云服务器或域名。仅选择控制台实际标为免费的CPU资源；没有免费配额时停止，不选择付费升级。

1. 打开 https://modelscope.cn/studios/create ，注册/登录魔搭账号，按平台要求完成必要验证。
2. 创建公开创空间，类型选择Streamlit，选择可用免费CPU资源；使用支持Python 3.10或更新版本的镜像。
3. 解压部署包，将里面的文件上传到空间根目录，而不是把zip文件直接当成源码上传。
4. 入口文件为app.py，依赖文件为requirements.txt。模型计算和五个模块由platform_app.py提供。
5. 部署后查看运行日志，确认依赖安装成功和应用进入运行状态。
6. 复制创空间网址，用未登录的浏览器和手机流量测试五个模块、预测、定价与下载。发布成功前不要把本地127.0.0.1网址发给别人。

默认使用本地AI模式，不需要付费模型API。包内只包含模拟经营数据和代码，未包含本机虚拟环境、密钥或本地审批/问答历史。公开空间可能公开源码，请勿额外上传真实业务或个人数据。

运行数据库首次从模拟数据快照初始化。平台提供可写/mnt/workspace时存入/mnt/workspace/smartprice_ai，否则使用临时目录；可用SMARTPRICE_STORAGE_DIR指定持久化目录。临时目录重启可能重置，重命名或迁移空间也可能影响平台持久化。重要记录请及时导出。

免费资源可能休眠、排队或调整配额，首次访问可能等待启动。不承诺全天候可用；部署后需要用国内网络实测。
