# SmartPrice AI — Stage 5 AI经营决策助手

## 1. 本阶段交付

第五阶段在 Stage 4 Streamlit 应用中增加 AI 经营决策能力：

- 自然语言经营问答：基于当前日期筛选范围的经营指标、产品、渠道、二次消费和价格弹性结果回答问题。
- 月度经营报告：生成可下载的 Markdown 管理报告，包含 KPI、环比变化、收入驱动因素、产品、渠道、二次消费及模型风险。
- 业绩变化归因：将收入变化分解为客流规模影响和游客人均收入影响；将贡献利润变化分解为收入变化减去变动成本变化。
- 管理提示：保留可解释规则引擎，提示容量、产品贡献利润率和价格弹性风险。

## 2. 本地模式

不配置任何外部模型也可以运行：
- 经营问答由本地规则引擎根据当前数据范围生成。
- 月度报告和差异归因均由 Pandas 计算。
- 本地模式不产生外部 API 费用，也不会将数据发送到第三方模型服务。

## 3. 可选外部大模型

如果需要更自然的问答表达，可以连接支持 OpenAI-compatible Chat Completions 接口的模型服务。

本应用使用以下环境变量：

- `SMARTPRICE_LLM_ENDPOINT`：完整的 Chat Completions API 地址。
- `SMARTPRICE_LLM_API_KEY`：模型服务密钥。
- `SMARTPRICE_LLM_MODEL`：服务商支持的模型标识。

### Windows PowerShell 当前会话配置示例

将占位值替换为模型服务商提供的实际信息：

```powershell
$env:SMARTPRICE_LLM_ENDPOINT = "https://your-provider.example/v1/chat/completions"
$env:SMARTPRICE_LLM_API_KEY = "your-real-api-key"
$env:SMARTPRICE_LLM_MODEL = "your-model-name"

python -m streamlit run app.py
```

仅当前 PowerShell 会话生效。也可以通过系统环境变量配置后重新打开终端。

**安全要求：**
- 不要把真实 API Key 写进 Python 源码。
- 不要将包含密钥的 `.env` 文件、截图或配置提交到 GitHub。
- `.env.example` 仅为占位模板，不包含真实密钥。
- 配置外部模型后，当前筛选范围的聚合经营数据和用户问题会发送到你配置的模型服务商。
- 不要向原型上传真实游客个人信息、支付信息或其他敏感数据。

如果没有完整配置三个环境变量，系统自动使用本地分析模式；外部模型调用失败时也会回退本地回答。

## 4. 页面使用

进入 Streamlit 左侧导航的「经营决策助手」：

### 自然语言经营问答
输入例如：
- 当前经营收入和贡献利润是多少？
- 哪个产品贡献利润最高？
- 线上、OTA和现场渠道表现如何？
- 餐饮与周边商品哪个毛利率更高？
- 2025年10月收入变化的主要原因是什么？
- 哪些产品的价格弹性估计不显著？

### 月度经营报告
选择月份，点击生成报告。报告可下载为 Markdown 文件，适合后续整理为 Word/PDF 或参赛材料。

### 业绩变化归因
选择月份，与上月比较：
- 收入驱动：客流规模影响 + 游客人均收入影响。
- 收入结构：门票及套餐、增量餐饮、周边商品。
- 成本变化：门票/套餐变动成本、二次消费商品成本。
- 贡献利润变化：收入变化 - 变动成本变化。

环比分析要求当前日期筛选范围同时包含本月和上月；若缺少上月数据，系统会明确提示，不会猜测。

### 管理提示
显示当前筛选范围内的规则提示和价格弹性显著性风险。

## 5. 关键口径

- 综合经营收入 = 门票及套餐净销售额 + 套餐外增量餐饮净销售额 + 周边商品净销售额。
- 套餐内餐饮收入分配字段不重复加总。
- 贡献利润 = 综合经营收入 - 门票/套餐变动成本 - 二次消费商品成本。
- 贡献利润未扣除固定成本、人工、租金、折旧、税费及融资费用，不等同于营业利润或净利润。
- 收入分解使用顺序分解：
  - 客流规模影响 =（本月游客数 - 上月游客数）× 上月游客人均收入。
  - 游客人均收入影响 = 本月游客数 ×（本月游客人均收入 - 上月游客人均收入）。
- 价格弹性仍来自模拟数据回归，不能被解释为真实市场的因果弹性。

## 6. 运行和验收

安装依赖：

```powershell
pip install -r requirements.txt
```

运行应用：

```powershell
python -m streamlit run app.py
```

运行第五阶段验收：

```powershell
python tests/validate_stage5.py
```

## 7. 当前限制

1. 底层数据为2025年模拟数据。
2. 本地问答是基于规则的意图识别和数据查询，不等同于完整通用大语言模型。
3. 外部大模型为可选配置；本次交付没有内置或代用户购买API服务。
4. 月度报告与归因仅对当前筛选范围内的数据负责。
5. 系统不自动执行调价、折扣发布或库存操作。
