# SmartPrice AI — Stage 4 Streamlit 产品原型

## 1. 产品说明

本阶段将前三阶段的模拟经营数据库、经营指标、价格弹性回归、客流预测回测和动态定价优化整合为一个 Streamlit 可交互应用。

应用面向主题乐园经营管理层，提供：
1. 经营管理驾驶舱
2. 经营数据分析
3. 客流需求预测
4. AI智能定价中心
5. 套餐及收益分析
6. 经营决策助手

注意：经营决策助手当前为可解释的规则引擎，不连接外部大语言模型。所有数据均为模拟数据，定价结果仅用于演示，不是实际经营指令。

## 2. 环境要求

- Windows 10/11
- Python 3.10 或更高版本
- 项目中已包含第二阶段 SQLite 数据库

## 3. Windows 启动方式

在项目根目录打开 PowerShell：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m streamlit run app.py
```

也可以双击 `run_app.bat` 启动。

浏览器打开 Streamlit 启动后显示的本地地址，通常为：

`http://localhost:8501`

## 4. 页面操作说明

### 经营管理驾驶舱
左侧选择日期范围，查看综合经营收入、游客数、游客人均收入、贡献利润和贡献利润率，并查看月度趋势、收入结构和产品收入排名。

### 经营数据分析
查看月度收入与贡献利润、渠道收入、日度经营指标、产品和二次消费明细。支持下载 CSV。

### 客流需求预测
查看历史滚动单步预测回测、MAE、WAPE、R²，并与简单的 Lag-7 基线比较。当前不是实时未来客流预测。

### AI 智能定价中心
选择模拟日期、优化目标、容量利用率上限和单次价格调整幅度，运行价格弹性回归与 SLSQP 定价优化。支持下载建议价格。若产品价格触及调整边界，页面会明确提示。

### 套餐及收益分析
比较产品净销售额、贡献利润率和餐饮/周边二次消费。贡献利润未扣除固定成本、人工、租金、折旧、税费和融资费用。

### 经营决策助手
规则引擎根据当前日期范围的经营数据和价格弹性结果生成管理提示。建议需要人工复核。

## 5. 主要目录

- `app.py`：Streamlit 主应用
- `smartprice_src/`：数据读取、经营指标、模型和页面分析函数
- `data/database/smartprice_ai.db`：SQLite 数据库
- `models/`：客流预测模型
- `reports/stage3/`：第三阶段模型结果和回测报告
- `tests/validate_stage4.py`：第四阶段数据层验收脚本
- `.streamlit/config.toml`：应用主题配置

## 6. 验收方式

```powershell
python tests/validate_stage4.py
```

该脚本检查数据库可读、六个页面所需数据函数、产品与渠道汇总、决策提示、价格优化输出和应用源代码语法。

## 7. 当前限制

1. 模拟数据只有2025年一个完整年度。
2. 客流页面展示的是历史滚动单步回测，不是当前日期的未来预测。
3. 定价模型的弹性来自模拟数据，尚未通过真实价格实验验证。
4. 部分价格建议可能触及约束边界，不能直接作为真实调价方案。
5. 决策助手为规则引擎，不具备自由对话式生成能力。
6. 应用当前为本地演示版，没有账号体系、权限管理、线上部署和真实数据接口。
