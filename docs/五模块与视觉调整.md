# 五模块与视觉调整

## 信息架构

一级导航严格为经营数据分析中心、市场需求预测、智能定价决策、收益与利润分析、AI经营决策助手。原八页内容按业务合并，市场监控与记录不再占用一级导航。原数据、模型和记录不迁移、不删除。

## 视觉方案

- 深蓝 #132D42：稳定的经营导航；青绿 #087E8B：主要操作和数据主线。
- 浅灰 #F3F6FA：工作区；白色 #FFFFFF：数据内容；琥珀 #E5A83B：辅助对比。
- 中文字体优先微软雅黑和苹方，使用系统字体避免外网依赖。标题、指标和正文分层，数字保持清晰。
- 页首以模块名称与业务说明作为层级；去掉重复标题和大渐变横幅。
- 四个核心KPI置于首页首行；收入、客流和游客消费的趋势分行展示。图表颜色与表格边界统一。
- 页签承载模块内任务；低频审计信息放在记录页签。窄屏自动折叠导航，内容列纵向排列。
- 键盘焦点清晰可见，尊重减少动画设置，不引入装饰动画或外部字体。

## 实施与验证

采用新安装的frontend-design技能指导；未使用Figma设计文件或Figma API，未引入React组件库依赖。界面仍由Streamlit与Plotly实现。

五模块的导航、页签、历史分析日期、审批作用域和共享定价结果纳入UI回归测试。业务口径与底层模型保持原有实现。
