# SmartPrice AI · 主题乐园智能定价与经营收益优化平台

基于阶段2–5材料整合的本地参赛演示版。Python 3.10、Streamlit、Plotly、SQLite；全部2025年经营、天气、竞品数据均为模拟数据。

## 启动

内网共享：双击 **run_lan.bat**，同一网络的其他人访问 `http://本机内网IP:8502` 即可操作。详见 [内网访问说明](deploy/内网访问说明.md)。

当前电脑已安装独立环境，双击 **run_app.bat**，访问 http://127.0.0.1:8501 。关闭运行窗口即停止服务。若端口已占用，请先关闭已有实例。

迁移电脑：安装Python 3.10后双击 **setup.bat**（首次需要网络），完成依赖安装、数据核验与模型重训，再双击 **run_app.bat**。依赖精确版本见 requirements-lock.txt，运行环境在 .venv 内。不要直接复制其他电脑的 .venv。

命令行启动：

```powershell
cd D:\codex\德勤挑战赛\SmartPrice_AI
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

## 五个核心模块

侧栏仅保留以下五项，顺序与设计一致：

| 模块 | 内部页签 |
|---|---|
| 经营数据分析中心 | 经营总览、销售与渠道明细 |
| 市场需求预测 | 历史回测、未来情景预测、季节与环境影响、需求预警 |
| 智能定价决策 | 定价模拟与建议、价格弹性与淡旺季策略、竞品价格对比、方案审批与记录 |
| 收益与利润分析 | 收入与利润贡献、套餐与二次消费、定价策略收益对比 |
| AI经营决策助手 | 经营问答与建议、异常与收益归因、经营分析报告、对话与报告记录 |

经营总览是默认首页。历史天气、季节性、假日和容量预警在需求预测模块；竞品对比在定价模块。预测及定价运行在定价模块内部查看，AI对话与报告在助手内部查看。

收益模块读取同一份定价结果和运行编号，不重新调用优化模型。当前会话有方案时优先展示该方案，否则读取最近一次已保存的定价运行。人工审批修改后的测算留在方案审批历史，原始策略对比保留原始快照。

页面采用统一深蓝导航、青绿主色、白色图表及指标卡；侧栏在窄屏自动折叠，内部内容按业务页签分组。设计参考新安装的frontend-design技能，在原有Streamlit框架内实现，不依赖Figma或React运行环境。

## 参赛演示（约5分钟）

1. 进入经营数据分析中心，展示四项核心指标、门票销量、收入结构与客流趋势；切换销售与渠道明细进行筛选。
2. 进入市场需求预测，查看回测误差及季节/天气/节假日统计。在未来情景预测中选择2026-01-01、7天和雨天，点击生成；再看需求预警。
3. 进入智能定价决策，设置85%容量、10%调价限制并计算三种策略；查看弹性、淡旺季说明和竞品对比。
4. 进入收益与利润分析的定价策略收益对比，核对与定价页相同的运行编号及收入、利润、客流数据。此步骤不重新计算。
5. 回到智能定价决策的方案审批与记录，选择对应运行，填写操作者并采纳、修改或拒绝；审批仍需通过所有约束。
6. 进入AI经营决策助手，提问“下周下雨，如何调整票价”，展开计算证据；在异常与收益归因查看月度变化，并在经营分析报告生成和下载月报。
7. AI对话和报告记录保存在助手内，审批记录保存在定价内，重启后仍可查询。

## 口径与模型说明

- 综合收入＝门票及套餐净销售额＋套餐外增量餐饮＋周边收入；套餐内餐饮分配不可重复相加。
- 贡献利润＝综合收入－门票/套餐变动成本－二次消费COGS；不是净利润。
- 客流随机森林：训练2025-01-08至08-31，校准09-01至10-31，测试11-01至12-31。历史回测为滚动单步；未来多步递归使用前序预测，不读取未来实际客流。
- 区间由校准期90%绝对残差估计，多步按步数平方根扩大，是参考区间，不保证未来覆盖率。产品售票量输出按历史客流份额分配。
- 未来预测起点仅支持历史末日后30天内，默认2026-01-01；跨年天气和假日由人工情景输入，不是实时预测。
- 定价使用含竞品价格、天气和日历控制项的产品log-log回归。需求对价格的反应不代表真实因果关系。
- 定价以产品基准价为参照，取产品边界、调价幅度与5元步长交集，通过整数规划选择每产品一个价格；在共同情景下最大化收入或贡献利润。
- 固定策略取最近可行基准价；规则策略节假日+10%、非节假日周末+5%、其他不变，并映射到共同价格网格。两种比较策略若超容量会显示约束不通过，不能审批为可行方案。
- 二次消费按历史每游客收入及成本率测算，排队时间为容量利用率函数的演示估计。默认85%是管理阈值，不是安全标准。
- 本地AI识别有限经营意图。历史日期范围及未来目标日期以页面控件为准；不支持的问题明确提示。

## 可选外部模型

保持默认无密钥即可使用。需接入时，在启动平台的PowerShell窗口设置：

```powershell
$env:SMARTPRICE_LLM_ENDPOINT="https://your-provider.example/v1/chat/completions"
$env:SMARTPRICE_LLM_API_KEY="your-key"
$env:SMARTPRICE_LLM_MODEL="your-model"
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

仅发送当前问题和聚合计算证据；外部模型负责组织表达，业务计算由本地工具执行。配置不完整或服务失败时回退本地。不要把真实密钥写入源码或提交到仓库。本项目未使用付费模型服务进行验收。

## 验证与维护

双击 verify.bat 运行新增业务测试和五模块及页签加载检查。原阶段验收：

```powershell
$env:PYTHONPATH=(Get-Location).Path
.\.venv\Scripts\python.exe run_stage3.py
.\.venv\Scripts\python.exe tests/validate_stage3.py
.\.venv\Scripts\python.exe tests/validate_stage4.py
.\.venv\Scripts\python.exe tests/validate_stage5.py
.\.venv\Scripts\python.exe validate_data.py
```

运行与审批数据保存在 data/database/smartprice_ai.db。备份该文件即可保留记录。原始数据生成脚本仅用于重建演示数据，重建前先备份数据库。数据库变化后点击侧栏“刷新数据与重新校验”。数据校验未通过时阻止预测、定价与AI计算。

结构：app.py为当前入口；legacy_app.py保留原界面帮助函数；smartprice_src提供数据、指标、预测、情景优化、工具和审计；tests保存验收；reports保存结果。审批为本地演示留痕，不具备生产身份认证或真实调价权限。
